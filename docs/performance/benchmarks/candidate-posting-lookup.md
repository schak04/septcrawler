# Candidate Posting Lookup Benchmark Output

Comparison: `bin/septcrawler-cli` captured before the lookup change versus the rebuilt optimised executable.

Environment: Linux-7.1.3-arch1-3-x86_64-with-glibc2.43

Compiler: GCC 16.1.1. Go: go1.26.5. Both C++ versions used the project Makefile configuration (`-std=c++20 -Wall -Wextra`).

Commands were run from the project root against the same index and documents. Each binary ran five times per query, alternating execution order by run. Wall time includes index loading, document loading, retrieval, ranking, and output.
